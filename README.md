# CreativeHQ Portfolio

Next.js 14 (App Router) + TypeScript + Tailwind CSS.

    npm install
    npm run dev

- Design tokens (colours, font): `tailwind.config.ts`
- Home page: `app/page.tsx` · Case studies: `app/work/[slug]/page.tsx`
- Project copy and placeholder images (picsum.photos): `lib/data.ts`
